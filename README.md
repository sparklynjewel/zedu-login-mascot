# Zedu login, premium

HNG 15, week 5, Task 2 (whimsical design). By Odofin Moronke, Team Cybertron.

A modern, sleek version of Zedu's login page that responds to what you do:

- a soft light and the Zedu bolt orb follow your mouse, and the card tilts slightly
- each key in the email box sends a ripple out of the orb; a valid email draws a tick
- the password box dims the lights for privacy, and a stronger password fills the bolt with gold
- Log in charges the bolt and releases a flash of light; empty boxes get a gentle shake and a hint
- press and hold the bolt to charge it; left alone, the page dims to standby

It's a mockup, not the real Zedu login. Use pretend details only: the form isn't connected to anything. It's one static page (`index.html`), built with CSS and a little JavaScript, and it respects "reduce motion".

The earlier mascot version is kept in `mascot.html`.
