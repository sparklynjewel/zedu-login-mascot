# Zedu login with a mascot

HNG 15, week 5, Task 2 (whimsical design). By Odofin Moronke, Team Cybertron.

This is a playful version of Zedu's login page, with a mascot that reacts to what you do:

- it peeks up and waves when you arrive
- its eyes and body follow your mouse
- it covers its eyes for the password
- it celebrates when you log in
- it falls asleep when you leave it alone

It's a mockup, not the real Zedu login. Use pretend details only: the form isn't connected to anything. It's built with CSS and a little JavaScript, it respects "reduce motion", and it's one static page (`index.html`).
